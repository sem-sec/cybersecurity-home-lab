# Security+ Core Concepts

## Covered
- CIA Triad (Confidentiality, Integrity, Availability) with real-world scenario application
- AAA framework (Authentication, Authorization, Accounting)
- Symmetric vs asymmetric encryption, and how TLS combines both in the HTTPS handshake
- Hashing: one-way functions, avalanche effect, password storage, integrity verification
- Digital certificates and Certificate Authorities: how trust is established and verified in HTTPS, and how this specifically defeats Man-in-the-Middle/Evil Twin attacks
- Common attack types: phishing (including spear phishing and Business Email Compromise), malware categories (virus, worm, trojan, ransomware, spyware), social engineering (pretexting, tailgating, vishing), SQL injection, Man-in-the-Middle/Evil Twin attacks

## Network Security Architecture
- Firewall types: packet-filtering, stateful, NGFW, WAF
- IDS vs IPS (detection vs prevention)
- VPN types: site-to-site, remote access
- Network segmentation: VLANs, DMZ
- Zero Trust security model ("never trust, always verify")
- Applied scenario reasoning: DMZ for internet-facing services vs. segmentation/Zero Trust for limiting lateral movement of authenticated entities
