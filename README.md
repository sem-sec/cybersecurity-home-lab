# Cybersecurity Home Lab — sem-sec

Hands-on documentation of my journey building practical IT and cybersecurity skills — from foundational Linux and networking through Windows Server / Active Directory infrastructure, working toward industry certification.

## What's covered so far

- Linux fundamentals (VM deployment, file system navigation, permissions, package management)
- Core networking (IP addressing, DNS, ports, TCP/UDP, subnetting, OSI model, firewalls, HTTP/HTTPS)
- Windows Server & Active Directory (building and configuring a domain controller lab environment)

## Goal

Developing practical, demonstrable cybersecurity skills through a self-built home lab, working toward CompTIA Security+ certification and hands-on experience with enterprise security tooling.
