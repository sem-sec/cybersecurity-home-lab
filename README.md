# Cybersecurity Home Lab — sem-sec

Hands-on documentation of my journey building practical IT and cybersecurity skills — from foundational Linux and networking through Windows Server / Active Directory infrastructure, working toward industry certification.

## What's covered so far

- Linux fundamentals (VM deployment, file system navigation, permissions, package management)
- Core networking (IP addressing, DNS, ports, TCP/UDP, subnetting, OSI model, firewalls, HTTP/HTTPS)
- Windows Server & Active Directory (domain controller deployment, OUs, users, security groups, Group Policy, domain-joined client, Kerberos authentication)
- Security fundamentals (CIA Triad, AAA framework, symmetric/asymmetric encryption, hashing, digital certificates & CAs, common attack types)
- Network security architecture (firewall types, IDS/IPS, VPNs, network segmentation, DMZ, Zero Trust)

## Repository Structure

- `linux-fundamentals.md` — Linux environment setup and core skills
- `networking-fundamentals.md` — networking concepts and tools
- `active-directory-lab.md` — Windows Server / AD domain build and configuration
- `security-plus-concepts.md` — core security theory and applied scenarios

## Goal

Developing practical, demonstrable cybersecurity skills through a self-built home lab, working toward CompTIA Security+ certification and hands-on experience with enterprise security tooling.
